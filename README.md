# FreshMart - Grocery E-Commerce Website

A full-stack grocery shopping web application built with PHP, MySQL, and Bootstrap. This project includes a complete customer-facing store and a secure admin panel for managing products, orders, and users.

## 🚀 Features
- User Signup/Login & Authentication
- Product Catalog with Categories & Filters
- Shopping Cart & Checkout System
- Order Placement & Tracking
- Admin Dashboard for Product, Order, & User Management
- Responsive Design (Mobile, Tablet, Desktop)

## 💻 Technologies Used
- **Frontend:** HTML5, CSS3, Bootstrap, JavaScript, AOS Animation
- **Backend:** PHP
- **Database:** MySQL (PDO)
- **Server:** Apache (XAMPP)

## ⚙️ How to Run This Project Locally
1. Install XAMPP and start Apache & MySQL.
2. Clone this repository or download the ZIP file.
3. Place the project folder inside `C:\xampp\htdocs\`.
4. Open phpMyAdmin (http://localhost/phpmyadmin) and create a database named `freshmart_db`.
5. Import the `freshmart_db.sql` file (if provided) or create the tables.
6. Open your browser and go to `http://localhost/Grocery_Shop`.
